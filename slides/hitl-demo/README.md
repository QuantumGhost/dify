# Dify HITL Demo Slides

This is a Slidev-based browser presentation for the Dify HITL Feishu IM demo.

## Files

- `slides.md`: main slide source

## Local usage

Install dependencies:

```bash
pnpm install
```

Start local preview:

```bash
pnpm dev
```

Build static browser output:

```bash
pnpm build
```

The generated static deck will be written to `dist/`.
